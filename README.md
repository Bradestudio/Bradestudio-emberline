Eight drifters drop into the Ashen Reach, a derelict freight yard at dusk. The ashfall zone closes in phases — loot fast, fight smart, be the last drifter standing. A browser FPS built with three.js: four original weapons (P8 Sidekick, VK-9 Tempest, BR-12 Breaker, LW-7 Longeye), seven rival bots with ember callsigns (ASH, CINDER, SLAG, RUST, FLINT, SMOKE, EMBER), floating nameplates, a shrinking zone, armour and medkits, kill feed, minimap, and procedural WebAudio sound. Eliminations and surviving each zone phase earn Ember ranks with stacking bonuses (max HP, reload, speed, armour, damage); kills add floating damage numbers, hitmarkers, kill banners and ember-burst explosions, and arrow keys turn the view so the game plays without pointer lock. Supply drops fall inside the zone on a light-pillar beacon, ashfall motes drift across the yard, and the end screen reports kills, damage, accuracy, survival time, placement and Ember rank. No network requests, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click to play. WASD to move, mouse to look and fire, right-click to aim, R to reload, 1–4 to switch weapons, Shift to sprint, Space to jump, E is not needed (loot is picked up by walking over it), M to mute, P to pause.
