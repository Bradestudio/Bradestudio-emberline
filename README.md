Eight drifters drop into the Ashen Reach, a derelict freight yard at dusk. The ashfall zone closes in phases — loot fast, fight smart, be the last drifter standing. A browser FPS built with three.js: four original weapons (P8 Sidekick, VK-9 Tempest, BR-12 Breaker, LW-7 Longeye), seven rival bots with patrol/loot/fight/retreat AI, a shrinking zone, armour and medkits, kill feed, minimap, and procedural WebAudio sound. No network requests, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click to play. WASD to move, mouse to look and fire, right-click to aim, R to reload, 1–4 to switch weapons, Shift to sprint, Space to jump, E is not needed (loot is picked up by walking over it), M to mute, P to pause.
